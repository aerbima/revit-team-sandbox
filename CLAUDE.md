# Правила проекта для Claude (ревью и генерация кода)

Правила кода — в `.github/copilot-instructions.md`: они общие для Copilot и Claude, дублировать их здесь не нужно.

## Как проверять pull request
1. Найди в заголовке код задачи `TASK-TS-…` и прочитай файл таска в `tasks/`: контракт, «Готово, когда», подводные камни.
2. Сверь код с требованиями учебного мини-ТЗ `docs/Мини-ТЗ.md` из строки «Требования ТЗ» таска. Требование не выполнено — замечание со ссылкой на ТР.
3. Проверь правила из `.github/copilot-instructions.md`: слои, `#if` только в `Sandbox.Revit`, `GetValue()` вместо прямого `IntegerValue`, транзакции `Trn_*`, контракт не изменён, атрибут `[ExcludeFromCodeCoverage]` снят с реализованного кода.
4. Revit API: сверяй сигнатуры для 2021 и 2025 — версии различаются.
5. Тесты: у каждого проверяемого без Revit требования есть тест с `[Trait("TR", …)]` и `[Trait("Task", …)]`.

## Формат замечаний
`BUG-<задача>-<NN> · S1…S4 · ТР-У.yy · файл:строка — что не так, как должно быть, как исправить.`
S1 — блокер, S2 — критично, S3 — значительно, S4 — незначительно.
Одобрение (Approve) ставит только тимлид. Ты пишешь комментарии и запрашиваешь изменения.
