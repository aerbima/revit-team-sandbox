# Учебное мини-ТЗ: маркировка помещений

Песочница проверяет **процесс** командной разработки, а не предметную область. Требования ниже нарочно простые, но устроены так же, как в настоящем ТЗ: у каждого есть номер `ТР-У.xx`, на номер ссылаются таски, тесты и замечания ревью.

## 0. Общие

| № | Требование |
|---|---|
| ТР-У.00 | Плагин собирается и загружается в Revit 2021, 2022, 2023, 2024 и 2025. На ленте вкладка «Sandbox», панель «Учебная», кнопка «О плагине» показывает версию плагина и Revit. *(сделано в каркасе)* |
| ТР-У.12 | Директивы `#if REVIT20xx` встречаются только в проекте `Sandbox.Revit`. *(проверяет тест `RepositoryRulesTests`)* |

## 1. Формат и генерация марок (ядро)

| № | Требование |
|---|---|
| ТР-У.01 | Марка помещения = префикс + разделитель + код уровня + разделитель + номер с ведущими нулями до заданного числа знаков. Пример: префикс «П», разделитель «-», 3 знака, уровень «01», номер 3 → `П-01-003`. |
| ТР-У.02 | Префикс — от 1 до 3 заглавных букв (кириллица или латиница). Иначе — `ArgumentException` с именем параметра `prefix`. |
| ТР-У.03 | Число знаков номера — от 1 до 5. Номер — от 1 до 10^знаков − 1. Иначе — `ArgumentOutOfRangeException`. Разделитель — любой символ, кроме буквы, цифры и пробела; иначе `ArgumentException`. |
| ТР-У.04 | Код уровня — от 1 до 4 букв или цифр. Иначе — `ArgumentException` с именем параметра `levelCode`. |
| ТР-У.05 | Разбор марки — обратная операция. Регистр префикса не важен, лишние ведущие нули в номере допустимы (`п-01-0003` = `П-01-003`). Строка, не подходящая под формат, даёт `false`, а не исключение. |

## 2. Поиск дублей (ядро)

| № | Требование |
|---|---|
| ТР-У.06 | Дубли — марки, которые после разбора по ТР-У.05 дают одинаковые код уровня и номер. Каждая группа дублей содержит исходные строки в порядке их появления во входном списке. |
| ТР-У.07 | Строки, которые не разбираются по формату, в группы дублей не попадают и возвращаются отдельным списком «нераспознанные». Пустой вход — пустой результат, не исключение. |

## 3. Команда «Марки помещений» (Revit)

| № | Требование |
|---|---|
| ТР-У.08 | На панели «Учебная» есть кнопка «Марки помещений». |
| ТР-У.09 | Команда берёт помещения (Rooms) активного вида, нумерует их на каждом уровне по возрастанию номера помещения (параметр «Номер») и записывает марку в параметр «Комментарии». Все изменения — в одной транзакции с именем `Trn_SetRoomMarks`. Помещения без уровня пропускаются. |
| ТР-У.10 | Код уровня — порядковый номер уровня по высоте, двумя цифрами: самый нижний уровень с помещениями — `01`. Функция «порядок → код» живёт в ядре и покрыта тестами. |
| ТР-У.11 | После выполнения открывается окно-итог: сколько помещений размечено, сколько пропущено, есть ли дубли среди марок, которые уже были в «Комментариях» до запуска (поиск по ТР-У.06). |

## 4. Качество сборки

| № | Требование |
|---|---|
| ТР-У.13 | Во всех проектах включены анализаторы .NET с уровнем `latest-Recommended` и проверка стиля при сборке. В конфигурациях Release любое предупреждение — ошибка сборки. |

## Формат марки по умолчанию

Префикс «П», разделитель «-», 3 знака номера. TASK-TS-05 меняет значение по умолчанию — это учебная регрессия.
